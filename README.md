📚 Study Manager

Study Manager is a simple and practical web application designed to help teachers organize student information, manage classes, and keep academic records in one place.

✨ Features

- 👨‍🎓 Organize student information.
- 🏫 Manage classes.
- 📋 Keep student records organized.
- 💻 Simple and user-friendly interface.
- 📱 Responsive design for different screen sizes.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
